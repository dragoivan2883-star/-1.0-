# Эксперимент: Навигатор звонка v2 DARK

Отдельный интерактивный HTML-прототип альтернативного интерфейса сценария продаж ОСАГО и мини-КАСКО.

## Как открыть

Скачайте `Alternativa_Navigator_v2_DARK.html` из этой папки и откройте двойным щелчком в любом современном браузере. Node.js, локальный сервер и установка зависимостей не нужны.

## Что можно проверить

- Развитие разговора по веткам ответов клиента.
- Быстрые возражения в шторке, без перехода на другой этап.
- Историю разговора и возврат на предыдущие решения.
- Режимы подсказок для начинающего и опытного менеджера.
- Тёмную цветовую схему и работу на узких экранах.

## Статус и границы

**Эксперимент для обсуждения, не готовый виджет amoCRM.**

- Данные демонстрационные. Нет интеграции с CRM, телефонией или отправкой сообщений.
- Скрипт, формулировки предложений и логика ветвлений нуждаются в утверждении заказчиком.
- Не заменяет файлы `src/`, `index.html`, `dev-server.mjs` и действующие тесты оригинального проекта.
- Прежде чем переносить решение в основную кодовую базу, нужно провести тестирование с менеджерами и отдельно спроектировать интеграцию.

## Как дальше работать

Оставляйте замечания в Draft PR. После согласования интерфейса переносим выбранные решения отдельными проверяемыми изменениями в основной проект.
