# Альтернатива | Ассистент продаж

Браузерный прототип помощника для менеджера при исходящем звонке по продлению ОСАГО. Сценарий помогает пройти разговор, ответить на возражение и отдельно предложить мини-КАСКО.

> **Статус:** этап 1 ТЗ — автономный прототип. Это ещё не виджет, установленный в amoCRM: интеграции, манифеста и чтения полей CRM пока нет.

## Что работает

- Пять этапов: приветствие, уточнение потребности, ОСАГО, мини-КАСКО и завершение разговора.
- Три варианта завершения: клиент готов оформить, хочет расчёт или отказался.
- 11 возражений доступны на любом этапе; открытие и закрытие подсказки сохраняет текущий этап.
- Режимы «Новичок» и «Опытный». Выбор сохраняется в `localStorage`, когда хранилище доступно.
- Подстановка демонстрационных данных. Если цена или страховщик не указаны, показывается нейтральная фраза без выдуманного предложения. Неподтверждённые условия мини-КАСКО не выводятся.
- Тексты сценария и возражений вынесены в JSON.

Все данные в `src/scripts/demo-client.json` вымышлены. Прототип не отправляет сообщения, не меняет данные CRM и не обращается к внешнему серверу.

## Запуск

Нужен Node.js 20 или новее. Установка пакетов и сборка не требуются.

```powershell
git clone https://github.com/dragoivan2883-star/-1.0-.git
cd .\-1.0-
node dev-server.mjs
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173) в браузере. Сервер слушает только `127.0.0.1`. Чтобы выбрать другой порт, задайте переменную `PORT` перед запуском. Прямое открытие `index.html` через `file://` не поддерживается из-за загрузки отдельных JSON-файлов.

## Проверка

```powershell
node --test
```

Тесты проверяют порядок этапов, основные развилки, возражения, сохранение этапа при смене режима и нейтральные фразы при пустых данных. Для ручной проверки пройдите путь «Удобно» → выбор потребности → ОСАГО → мини-КАСКО → один из трёх результатов. Отдельно проверьте «Неудобно», «В чём разница?», отказ от мини-КАСКО и открытие возражения на разных этапах.

## Изменение текстов и оформления

| Файл | Назначение |
| --- | --- |
| `src/scripts/osago.json` | Этапы, кнопки, длинные и короткие фразы, подписи интерфейса |
| `src/scripts/objections.json` | Ответы на возражения |
| `src/scripts/demo-client.json` | Вымышленная карточка для проверки подстановки |
| `src/styles/widget.css` | Оформление и переменная цвета `--accent` |

Пять дополнительных ответов в `objections.json` помечены `draft`: заказчик должен утвердить их до выпуска. После изменения JSON обновите страницу. Ключ продукта `osago` оставлен для расширения сценариев в будущих версиях.

## Структура

```text
index.html             Точка входа
dev-server.mjs         Локальный сервер без зависимостей
src/main.js            Отрисовка и обработчики интерфейса
src/state.js           Переходы сценария
src/phrases.js         Подстановка данных и нейтральные фразы
src/scripts/           Конфигурации сценария и демонстрационные данные
src/styles/widget.css  Стили
tests/                 Автоматические проверки
docs/PLAN.md           План следующих этапов
```
